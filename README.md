# common-harness

보고서, 기획안, 조사, 정산, QA, 코드, 업무 자동화처럼 정확성과 재작업 비용이 중요한 작업을 위한 스킬입니다. 먼저 완료 조건을 정하고, 사용자에게 전달하기 전에 실제로 확인합니다.

## 사용법

- Claude에서는 `/common-harness`를 붙여 요청합니다.
- ChatGPT나 Codex에서는 설치된 스킬 목록에서 `common-harness`를 선택해 요청합니다.
- “하네스로”, “검증해서”, “정확하게”, “꼼꼼하게” 같은 표현으로도 복잡한 작업의 검증을 요청할 수 있습니다. 플랫폼과 대화 맥락에 따라 자동 호출 여부가 달라질 수 있습니다.
- 짧은 후속 질문과 단순 문구 수정에는 필요한 확인만 합니다. 자료로 해결하기 어려운 핵심 조건만 묻고, 되돌리기 쉬운 결정은 가정을 밝히고 진행합니다.

| 요청 예시 | 확인하는 내용 |
|---|---|
| `/common-harness 이 기업의 공고를 기준으로 지원 적합성을 평가해줘` | 공고의 출처와 기준일을 대조하고 경력 근거와 적합성 판단을 구분합니다. |
| `/common-harness 쿠폰 규칙을 반영해 정산 검증표를 수정해줘` | 정상·예외 주문의 기대 금액을 계산하고 바뀐 항목과 합계를 대조합니다. |
| `/common-harness Notion 팀 홈에 개인 작업실을 만들고 연결을 확인해줘` | 변경 후 샘플 담당자의 프로젝트·태스크·산출물 연결과 조회 결과를 확인합니다. |

## 작동 방식

1. 요청의 목적·독자·형식·제약을 파악하고, 필수 요구사항마다 확인할 결과를 정합니다.
2. 중요한 주장과 숫자에 사용자 제공, 원문 대조, 재계산, 추정·가설, 미검증 중 해당 상태를 기록합니다. 후속 답변에도 근거 상태와 조건을 이어갑니다.
3. 과업에 맞는 계산, 자료 대조, 실행, 결과 재조회 등으로 완료 조건을 확인합니다. 예를 들어 사용자가 준 입력으로 계산을 다시 해도 그 입력은 사용자 제공으로 유지합니다.
4. 필요한 부분을 수정한 뒤 영향 범위를 다시 확인합니다. 필수 조건이 미충족이거나 미확인이면 확인 가능한 결과와 함께 남은 조건과 영향을 알립니다.

## 대화 내 명령

| 명령 | 동작 |
|---|---|
| `-harness off` 또는 `-하네스 꺼줘` | 이후 요청에서 스킬 절차를 끕니다. |
| `-harness skip <요청>` 또는 `-하네스 이번만 꺼줘 <요청>` | 같은 메시지의 요청 하나에만 스킬 절차를 건너뜁니다. |
| `-harness status` 또는 `-하네스 상태` | 스킬 절차의 현재 상태를 한 줄로 답합니다. |

켜려면 스킬을 다시 명시적으로 호출합니다. 끈 뒤 특정 요청의 검증 절차를 요청하면 그 요청에만 적용합니다.

이어지는 작업에 필요한 기록은 저장할 수 있는 환경에서 `.common-harness/notes.md`에 남길 수 있습니다. 같은 작업의 조건과 근거 상태, 산출물 위치를 중심으로 기록합니다. 저장이 불가능하면 현재 대화를 참고합니다. 새 대화로 이어가려면 진행 중인 기준·근거·남은 검증을 담은 요약을 요청하세요.

## 설치 및 업데이트

**Claude 앱**

1. `common-harness` 폴더를 ZIP으로 압축합니다. ZIP 안에 `common-harness/SKILL.md`가 있어야 합니다.
2. Claude의 **사용자 정의 > 스킬**에서 ZIP을 업로드합니다. 기존 스킬을 업데이트할 때는 최신 ZIP을 사용합니다.
3. 스킬 목록에서 `common-harness`를 켭니다. 화면이 다르면 [Claude에서 스킬 사용하기](https://support.claude.com/ko/articles/12512180)를 확인하세요.

**Claude Code**

이 저장소의 `common-harness/SKILL.md`를 프로젝트의 `.claude/skills/common-harness/SKILL.md`에 둡니다. 업데이트할 때도 같은 경로의 파일을 교체합니다.

## 이전 버전의 시험 결과

이 수치는 이전 버전으로 수행한 Claude 시뮬레이션 결과입니다. 현재 버전의 품질 향상 폭과 추가 토큰은 새로 측정해야 합니다.

| 시험 | 이전 버전의 결과 |
|---|---|
| 조건 준수, 요청 50개 | 스킬 미사용 48/50, 사용 50/50 |
| 모호한 요청 6개를 5회씩 반복했을 때 첫 질문 여부 | 미사용 20/30, 사용 30/30 |
| 최종 산출물 12쌍 블라인드 평가, 5점 만점 | 미사용 4.62점, 사용 4.82점 |
| 작업 기록, 끄기 명령, 기록 정리 등 31회 | 완전 통과 28회, 부분 통과 3회 |
| 질문 규칙 29회 | 시험에서 정한 제약 위반 0회 |

현재 버전을 비교할 때는 같은 모델과 자료로 실행하고, 초안 이후 조건 변경도 포함합니다. 필수 요건 누락, 사실·수치 오류, 사용 가능 여부, 최종본까지 필요한 추가 대화 횟수를 비교합니다.
